# STARTIN 작업 인수인계 — 2026-10-02

## 집 Codex가 먼저 볼 상태

- 이 저장소는 React·CSS·GSAP 원본 소스다. 렌더링 결과물만 올린 것이 아니므로 직접 수정할 수 있다.
- 최신 main을 받되 집 PC의 기존 미커밋 변경은 먼저 보존한다.
- 인트로는 15초다. 마지막 화면 체류만 늘리던 20초 설정은 사용자 피드백으로 제거했다. 시간 자체보다 연출의 완성도가 우선이다.
- 사용자가 최종 디자인을 승인한 상태는 아니다. 기능 검증 통과를 시각적 최종 컨펌으로 해석하지 않는다.

## 이번 업로드 내용

- 인트로 내부의 일시정지·다시보기·0.25×/0.5×/1× 배속·타임라인 슬라이더·검수 모드.
- 슬라이더를 움직이면 자동으로 검수 모드에 진입하고 정지한다. 검수 모드에서는 끝까지 재생해도 메인으로 자동 이동하지 않는다.
- App에 남아 있는 흰색 브랜드 전환 레이어로 인트로 → 메인을 연결한다. 0.65초 덮기 + 1.35초 로고 체류·걷히기, 총 2초. 모션 감소 설정은 즉시 진입한다.
- 조건 창과 서비스 창 모두 기울어져 등장한 뒤 정면으로 돌아온다. 같은 평면의 내부 요소를 각 창의 단일 원근 카메라로 투영한다. 조건 창은 6.2초, 서비스 창은 14.6초에 정면 정렬한다.
- 파란 장면 제목을 흰색으로 통일했다. 헤더·하단의 mix-blend-mode: difference를 제거해 파란 배경에서 글자가 노랗게 반전되는 문제를 수정했다.
- 상단 ®는 Arial 17px·일반 굵기·독립 간격, NEXT 배경은 약 15% 불투명도로 조정했다.
- 아침에 제공받은 모션 모아보기 원본을 public/motion-preview에 복원했다. 약 2MB, HTML 및 원본 ZIP 포함. 일부 예제는 CDN 의존이므로 인터넷 연결이 필요하다.

## 실행·검수 경로

- npm ci 후 npm run dev 실행. 터미널에 나온 서버 주소를 사용한다.
- /intro: 인트로 직접 보기. /main: 구직 메인.
- /motion-preview/index.html: 아침에 만든 모션 비교실.
- 서버 준비 요청은 커버 mount에서 시작한다. 무료 Render의 cold start 자체를 제거하지는 않는다.
- 메인에는 커버 다시보기 버튼을 추가하지 않는다.

## 검증

- 빈 시간 제거·서비스 원근 수정까지 빌드와 커버 테스트 6개 통과.
- 조건 창·가독성 추가 수정은 빌드와 관련 테스트 2개 통과.
- 전체 최신 테스트 결과는 verification/LATEST_VALIDATION.md 및 아래 최신 실행 결과를 기준으로 확인한다.
- 구버전 E2E는 37개 공고·5개 기업 및 예전 UI 기대값 때문에 실패 이력이 있다. 현재 데이터는 1,000개 공고·150개 기업이다.
- Git push 성공과 Render Live는 별도 확인 항목이다. 이 업로드를 곧바로 배포 완료로 취급하지 않는다.

## 남은 작업과 판단 기준

- 사용자는 라이브러리나 효과 수가 아니라 모션의 체급·구도·리듬·가독성을 요구한다. 좋은 레퍼런스를 그대로 복사하는 것이 목표가 아니다.
- 단지 길이를 늘리는 수정은 하지 않는다. 20초가 필요하면 실제 장면 발전이 있어야 한다.
- 정면으로 돌아오는 연출은 사용자가 수용했다. 동일한 방향으로 앞뒤 창의 움직임을 유지한다.
- 1920×1080에서 정상 속도로 전체 흐름을 확인하고, 검수 도구로 각 전환을 확인한다. 모바일도 컨트롤 잘림 여부를 확인한다.
- 필요하면 NEXT 대비와 ®를 실제 모니터에서 추가 조정한다. 변경된 색상·원근의 최종 미감은 사용자 컨펌 대상이다.
- 모션 비교실의 예제 선택·재생이 최신 프로젝트에서도 정상인지 추가 확인한다. 파일 복원만으로 예제 전체 검증 완료라고 하지 않는다.
- 유료 서버는 아직 구매·플랜 변경하지 않았다. 명확한 승인 없이 결제하지 않는다.
