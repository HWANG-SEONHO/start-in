## 반드시 덜어낼 것 (탈락 조건)

이 명세는 "이래야 한다"가 아니라 "이러면 안 된다"만 정한다. 아래에 걸리지 않으면 어떤 스타일이든 후보다.

1. **AI 기본값.** "AI에게 아무 조건 없이 이 화면을 만들어 달라고 하면 이렇게 나오나?"에 '그렇다'면 완성도가 높아도 탈락. (4판 사용자 판정)
   - 예: 짙은 남색 바탕 + 보라 그라데이션 요약 카드 + 둥근 카드 격자 + 막대·도넛 차트 대시보드 / 흰 바탕 + 요금제 카드 3~4개 + 가운데 강조 테두리 + 체크 목록 가격표 / 흰 바탕 + 파란 버튼 SaaS 첫 화면.
2. **읽히지 않는 글.** 사진·배경에 묻혀 안 읽히는 글자. (정석: 대비. 4판 STPMJ 탈락)
3. **어디를 봐야 할지 모르는 화면.** 모든 요소가 같은 무게로 경쟁한다. (정석: 위계)
4. **화면 종류가 자산과 다름.** FAQ 자산인데 회사 첫 화면을 찍는 식. 업종은 달라도 된다.
5. **흔한 기본 구성 그대로.** 템플릿을 거의 고치지 않은 화면, 종합몰 기본 상품 화면, 정돈만 되고 아무 선택도 보이지 않는 화면. (4판 헬독스·핫트랙스·라포스튜디오 탈락)

## 어디서 찾나

- 한국 회사·브랜드·스튜디오의 한국어 사이트를 우선한다.
- 기능 자산(FAQ·로그인·폼·표·대시보드·가격표)은 기능 전문 서비스뿐 아니라 브랜드·스튜디오·작가 사이트 안의 해당 화면까지 넓게 찾는다. 어느 쪽이든 탈락 조건만 피하면 된다.
- 한국에서 기준을 넘는 곳을 못 찾았을 때만 해외 사이트를 자산당 최대 1곳 넣고 목록에 `해외 대체`라고 적는다. 영어 데모를 표시 없이 넣지 않는다.
- 탈락: 템플릿 모음, 포털 첫 화면, 공공기관, 종합몰(여러 브랜드를 파는 쇼핑몰)의 상품 화면, 빽빽한 상품 목록, 대기업 고객센터·약관·공지·마이페이지.
- **찾는 자산이 그 기능 자체일 때는 "운영용 보조 페이지 제외"를 적용하지 않는다.** 예: 로그인 자산은 로그인 화면을 찾아야 한다. 로그인 화면은 로그인 전에 누구나 보는 공개 화면이다(로그인은 하지 말 것).
- 상품 자산은 브랜드가 직접 운영하는 쇼핑몰의 상품 상세만.
- 이미 쓴 사이트·브랜드(합격.md와 판정 기록에 적힌 곳)는 다시 쓰지 않는다.

## 찍는 법

- 사이트당 데스크톱 1장, 1920×1080. 모바일·전체 페이지 캡처는 하지 않는다.
- **찍을 부품이 화면 가운데에 잘리지 않고 온전히 들어오게 스크롤한 뒤 찍는다.** 위가 잘리거나 빈 바탕이 반 이상이면 다시 찍는다.
- 동작이 핵심인 자산은 조작한 뒤의 대표 장면 1장: FAQ는 답 하나 펼침, 가격표는 전환한 상태.
- **폼:** 아무것도 입력하지 않고 보내기를 눌러 화면 안의 오류 표시를 띄운 장면을 찍는다. 단 누르기 전에 브라우저 검증·화면 오류만 뜨는지 확인하고, 실제로 전송될 것 같으면 누르지 말고 빈 폼을 찍고 `검증 확인 불가`로 적는다.
- **표:** 정렬 동작은 확인되면 좋지만 합격 조건이 아니다. 표의 생김새(열 구성, 줄 간격, 상태 표시)가 기준을 넘으면 된다.
- 로그인·결제·실제 전송은 하지 않는다. 쿠키 창·팝업은 닫고, 로딩이 끝난 뒤 찍는다. 차단·오류·빈 화면이면 다른 곳을 찾는다.
