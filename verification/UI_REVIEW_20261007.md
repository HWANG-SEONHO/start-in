# 2026-10-07 UI 검증

기준: 학교 수정본 `8225c03`에 인증 화면·버튼·모바일 진입을 수정한 로컬 코드. Edge/Playwright와 실제 로컬 SQLite API를 사용했으며 API 응답을 모의로 대체하지 않았다. 운영 DB는 검증 대상이 아니다.

- PC: 3840×2160, 2560×1440, 1920×910, 1920×900, 1536×864, 1280×720, 1024×768의 메인·로그인·가입 21개 조합.
- 휴대폰: 360×800, 390×844, 430×932의 메인·공고·로그인·가입 12개 조합.
- 총 33개 조합: 문서 가로 넘침 0, JavaScript 페이지 오류 0.
- 4K 로그인·가입 사진 영역 실측: 1920×1080. 모든 해상도에 1920 너비를 강제하는 설정은 아니다.
- 사진 로딩 완료 후 1920×910 페이지 전체 캡처: `assets/images/main-final-20261007.png`, `login-final-20261007.png`, `register-final-20261007.png`.

## 기능 검사

- 비밀번호 확인 불일치 차단 → 실제 가입 → MY 이동.
- 실제 지원 기록의 메모 저장, 확인창을 통한 지원 취소.
- PDF 파일 업로드 → 교체 → 삭제 확인. PDF 업로드 흐름용 최소 파일을 사용했으며 PDF 뷰어의 문서 내용 렌더링 검사는 아니다.
- 휴대폰 자동 `/m` 이동과 하단 홈 링크.
- 390×844에서 실제 모바일 가입·MY 세 탭 이동·PDF 업로드/삭제·상세 필터 펼치기/접기와 지역 선택 유지. 가로 넘침·실행 오류 없음.

## 제한

브라우저 모바일 에뮬레이션 결과이며 실제 iOS·Android 기기 전체를 검사한 것은 아니다. 소셜 로그인·비밀번호 찾기는 준비중이다. 외부 AI 공급자 응답과 Render 배포 완료는 별도 검사 대상이다. 기존 WebP는 사용자 결정에 따라 갱신하지 않았다.

기존 `dist` 안의 로컬 실험 폴더 삭제가 EPERM으로 막혀 프로덕션 빌드는 `.cache/instruction-build`를 출력 경로로 사용했다. 해당 출력은 Git에 포함하지 않는다.
