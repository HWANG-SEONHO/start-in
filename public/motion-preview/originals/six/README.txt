START IN — GSAP + Motion 독립 실행 버전

실행:
1. ZIP을 풉니다.
2. 안의 HTML 파일을 더블클릭합니다.
3. Vite / npm / React 개발서버는 필요 없습니다.

실제 사용 라이브러리:
- GSAP 3.13.0 — 메인 장면 타임라인 / 타이포 / 마스크 / 시퀀스
- Motion 13.4.0 — 포인터 반응 / REPLAY 버튼 spring microinteraction

중요:
- 실제 GSAP/Motion은 CDN에서 불러오므로 첫 실행 시 인터넷 연결이 필요합니다.
- CDN 로딩이 실패해도 같은 HTML 안의 Web Animations fallback이 재생되어 화면이 완전히 멈추지 않습니다.
- 좌하단 배지에 'GSAP 3.13 + Motion 13.4 · ACTIVE'가 뜨면 실제 GSAP/Motion으로 재생 중입니다.
- 'OFFLINE FALLBACK'이 뜨면 CDN을 못 불러온 상태입니다.

품질 방향:
- 이미지/로고 심벌 없이 타이포그래피가 주인공
- 검정 / warm ivory / START IN green 중심
- 각 버전 약 23~25초
- REPLAY 버튼 제공
