# START IN

> **빠르게 찾고, 가볍게 보고, 바로 나갈 수 있는 구직 탐색 프로젝트.**

`START IN`은 구직사이트에 들어갔을 때 쏟아지는 정보부터 보는 대신, **내 조건에 맞는 채용시장이 지금 어떤지 빠르게 확인하는 경험**에서 시작한 프로젝트입니다.

지역과 조건을 고르고, 지도를 보고, 공고를 확인하고, 필요하면 AI 검색을 이용합니다. 볼 것을 봤으면 오래 붙잡아두지 않는 화면을 지향합니다.

🧩 **[풀스택 기능 확장 버전 바로가기](https://start-in-web.onrender.com/)**  
💻 **[풀스택 버전 소스 · codex-latest](https://github.com/HWANG-SEONHO/start-in/tree/codex-latest)**

> **현재 두 버전의 역할이 다릅니다.**  
> `main`은 지금까지 다듬어 온 **PC 메인 디자인 기록과 시각 기준**을 보존합니다.  
> `codex-latest`는 React · FastAPI · PostgreSQL · 로그인 · 저장공고 · 지원현황 · PDF · AI 검색 등 실제 기능을 연결해 보는 **학습·기능 확장 버전**입니다.

## 풀스택 기능 확장 버전

`codex-latest`에서는 디자인 시안을 단순히 보여주는 단계에서 더 나아가 실제 서비스 구조를 붙이고 있습니다.

현재 연결한 주요 기능은 다음과 같습니다.

- React 기반 화면 및 Router
- 검색 · 복수 필터 · 정렬 · 공고 상세
- FastAPI 백엔드
- PostgreSQL + SQLAlchemy + Alembic
- 회원가입 · 로그인 · 로그아웃
- 사용자별 저장공고 · 지원현황
- PDF 이력서 업로드/다운로드/교체/삭제
- 자연어 AI 검색 구조와 일반 검색 fallback
- Render를 이용한 프론트엔드 · 백엔드 · DB 배포

### 현재 디자인 상태

풀스택 버전은 기능을 연결하는 과정에서 **메인 디자인 버전과 일부 화면 구성이 달라졌거나 디자인이 깨진 부분이 남아 있습니다.**

이 프로젝트는 완성된 상용 서비스를 한 번에 만드는 것이 아니라, 실제 개발을 진행하면서 **React → 상태/이벤트 → API → DB → 인증 → 배포 → AI 기능**을 하나씩 이해하고 연결해 보는 학습 프로젝트이기도 합니다.

따라서 현재의 풀스택 화면을 최종 디자인으로 고정하지 않습니다.  
**학습 진도가 진행될 때마다 이미 구현한 기능을 다시 읽고 수정하면서 디자인을 메인 기준에 맞춰 보완하고, 새로 만드는 페이지의 디자인도 함께 업데이트할 예정입니다.**

기능을 먼저 붙였다는 이유로 디자인을 포기하는 것이 아니라, **배운 내용을 실제 프로젝트에 적용할 수 있게 되는 시점마다 기능과 디자인을 다시 합치는 방식**으로 발전시키는 것이 목표입니다.

## 핵심 경험

- **AI 채용 검색**  
  자연어로 원하는 조건을 입력해 관련 공고를 찾는 흐름을 목표로 합니다.

- **체크형 상세 조건**  
  지역 · 직무 · 학력 · 경력 · 고용형태 · 급여 · 근무조건 · 기업형태 · 복리후생 등을 한눈에 보고 바로 고릅니다.

- **지역별 채용 밀도 지도**  
  숫자를 하나씩 읽기 전에 어디에 채용기회가 몰려 있는지 먼저 느낄 수 있는 지도를 지향합니다.

- **공고 탐색**  
  조건을 바꾸고, 결과를 비교하고, 관심 있는 공고를 빠르게 확인하는 흐름을 우선합니다.

## 프로젝트 진행 흐름

`아이디어 → HOME 1차 초안 → PC 디자인 정리 → HTML/CSS/JS 구현 → 브라우저 미세조정 → React 전환 → API/DB 연결 → 인증/사용자 기능 → 배포 → AI 기능 확장`

현재는 **메인 디자인 기록과 풀스택 기능 버전을 분리해서 보존**하고 있습니다.

메인 디자인은 1920×1080 PC 환경을 기준으로 발전시켜 왔으며, 풀스택 버전의 화면과 추가 페이지는 학습·개발 진행에 맞춰 계속 수정합니다.

현재 포함된 공고·기업 정보 등은 프로젝트 기능 확인을 위한 데모 데이터입니다.
