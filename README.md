# STARTIN

> **빠르게 찾고, 가볍게 보고, 바로 나갈 수 있는 AI 구직 탐색 프로젝트.**

`STARTIN`은 지금까지 배운 웹 기술을 실제 서비스 흐름으로 연결해보기 위한 학습·포트폴리오 프로젝트입니다.

대형 구직사이트처럼 정보를 많이 쌓는 것보다, **내 조건에서 지금 볼 만한 공고가 얼마나 있는지 빠르게 확인하는 경험**을 먼저 만듭니다.

## HOME · 1차 초안

![start_in home draft](assets/images/home-draft-20260919.png)

처음 방향을 잡았을 때의 HOME 1차 초안입니다.

이때부터 STARTIN의 핵심은 크게 바뀌지 않았습니다.

**조건을 고른다 → 결과를 바로 본다 → 지역별 채용 밀도를 본다 → 필요한 정보만 더 본다.**

로고, 히어로, 지도, 필터와 공고영역의 디테일은 이후 실제 구현 과정에서 계속 수정했습니다.

## HOME · 현재 구현

![STARTIN current home](assets/images/home-current-20260925.png)

1차 초안을 기준으로 실제 HTML/CSS/JS 화면을 만들고 브라우저에서 직접 조정한 현재 메인 프로토타입입니다.

### 현재 구현된 화면

- 자연어 형태의 **AI 채용 검색 UI**
- 지역 · 직무 · 학력 · 경력 · 고용형태 · 급여 · 근무조건 · 기업형태 · 복리후생 필터
- **부산 지역 채용 현황 지도 / 목록 전환**
- 지도 지역 선택 및 확대 · 축소
- 예시 채용공고 검색 · 정렬
- 관심 공고 저장 (`localStorage`)
- **1920×1080 PC 화면**을 기준으로 한 메인 페이지

현재 화면의 기업명·공고·연봉·공고 수는 UI 구현을 위한 예시 데이터입니다.

## STARTIN이 중요하게 보는 것

STARTIN의 첫 화면에서 가장 중요하게 보는 것은 기능의 개수보다 **답을 얻는 속도**입니다.

**조건을 고른다 → 지도를 본다 → 공고를 본다 → 필요하면 AI에게 묻는다 → 볼 것을 봤으면 나간다.**

처음부터 정보를 전부 쏟아내기보다, 필요한 사람이 필요한 만큼만 더 들어갈 수 있는 구직 탐색 경험을 만들고 있습니다.

### 핵심 경험

- **AI 채용 검색**  
  등록된 채용공고 · 기업정보 · 현직자 인사이트를 바탕으로 자연어로 원하는 조건을 찾는 방향을 목표로 합니다.

- **체크형 상세 조건**  
  필요한 조건을 눈으로 빠르게 훑고 바로 선택할 수 있게 합니다.

- **조건 변경에 따른 즉시 갱신**  
  조건이 달라지면 공고 수와 지역별 채용 밀도도 함께 달라지는 구조를 목표로 합니다.

- **지역별 채용 밀도 지도**  
  숫자를 하나씩 읽기 전에 어디에 공고가 몰려 있는지 먼저 느낄 수 있는 지도를 지향합니다.

- **빠른 공고 탐색**  
  검색을 마친 뒤에도 불필요하게 오래 머물게 하기보다 필요한 공고를 빠르게 확인하는 흐름을 우선합니다.

## 개발 과정

현재까지의 흐름은 다음과 같습니다.

`제품 아이디어 → HOME 1차 초안 → 디자인 기준 정리 → HTML/CSS/JS 구현 → 브라우저 미세조정 → 현재 메인 프로토타입`

다음 단계에서는 현재 화면의 디자인을 기준으로 React 컴포넌트와 상태·이벤트 구조를 연결합니다.
