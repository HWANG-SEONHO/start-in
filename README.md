# STARTIN

> **내 조건에 맞는 채용시장을 빠르게 확인하고, 볼 것만 보고 나갈 수 있는 구직 탐색 프로젝트.**

STARTIN은 복잡한 구직사이트에서 필요한 정보를 찾기까지 오래 걸리는 경험을 줄여보자는 생각에서 시작했습니다.

지역과 조건을 고르면 **공고 수·지역별 밀집도·채용공고가 한 흐름에서 바로 이어지는 화면**을 만드는 것이 현재 핵심입니다.

![STARTIN current home](assets/images/home-current-20260925.png)

## 현재 구현

- 자연어 형태의 **AI 채용 검색 UI**
- 지역 · 직무 · 학력 · 경력 · 고용형태 · 급여 · 근무조건 · 기업형태 · 복리후생 필터
- **부산 지역 채용 현황 지도 / 목록 전환**
- 지도 지역 선택 및 확대 · 축소
- 예시 채용공고 검색 · 정렬
- 관심 공고 저장 (`localStorage`)
- 1920×1080 PC 화면을 기준으로 한 메인 페이지

현재 화면의 기업명·공고·연봉·공고 수는 **UI 구현을 위한 예시 데이터**입니다. 실제 채용 데이터나 실제 AI 검색 서비스는 아직 연결하지 않았습니다.

## 프로젝트 방향

STARTIN의 첫 화면에서 가장 중요하게 보는 건 기능의 개수보다 **답을 얻는 속도**입니다.

**조건을 고른다 → 지도를 본다 → 공고를 본다 → 필요하면 AI에게 묻는다 → 볼 걸 봤으면 나간다.**

처음부터 정보를 전부 쏟아내기보다, 필요한 사람이 필요한 만큼만 더 들어가게 만드는 방향으로 개발하고 있습니다.

## 현재 단계

`제품 방향 → PC 메인 디자인 → HTML/CSS/JS 구현 → 브라우저 미세조정 → 현재 메인 프로토타입`

다음 개발은 현재 화면을 기준으로 React 컴포넌트와 상태/이벤트 구조로 옮기는 단계에서 이어갑니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 현재 프로토타입을 볼 수 있습니다.

소스 구조상 `index.template.html`과 `jobs-panel.html`을 수정한 경우에는 다음 명령으로 `index.html`을 다시 만들 수 있습니다.

```bash
python build.py
```

## 화면 기준

- PC master viewport: **1920×1080**
- 기본 테마: **White mode**
- 1920px보다 좁은 화면에서는 원본 구성을 유지하면서 축소
- 현재는 PC 메인 화면을 우선 구현
