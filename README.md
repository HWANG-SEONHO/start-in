# STARTIN

> **빠르게 찾고, 가볍게 보고, 바로 나갈 수 있는 구직 탐색 프로젝트.**

`STARTIN`은 구직사이트에 들어갔을 때 쏟아지는 정보부터 보는 대신, **내 조건에 맞는 채용시장이 지금 어떤지 빠르게 확인하는 경험**에서 시작한 프로젝트입니다.

지역과 조건을 고르고, 지도를 보고, 공고를 확인하고, 필요하면 AI 검색을 이용합니다. 볼 것을 봤으면 오래 붙잡아두지 않는 화면을 지향합니다.

🌐 **[STARTIN 사이트 바로가기](https://hwang-seonho.github.io/start-in/)**

## HOME · 1차 초안

![STARTIN HOME 1차 초안](assets/images/home-draft-20260919.png)

처음으로 STARTIN의 방향이 잡힌 HOME 1차 초안입니다.

이때 정한 큰 흐름인 **조건 선택 → 지역별 채용 밀도 → 공고 확인**은 유지하면서, 이후 실제 구현 과정에서 화면의 구조와 디테일을 계속 다듬었습니다.

## HOME · 현재 구현

![STARTIN 현재 HOME](assets/images/home-current-20260925.png)

현재 HTML/CSS/JS로 구현한 PC 메인 화면입니다.

1차 초안 이후 헤더, 히어로, AI 검색, 상세 필터, 부산 지도, 채용공고 영역을 실제 브라우저에서 조정하며 현재 형태까지 발전시켰습니다.

## 핵심 경험

- **AI 채용 검색**  
  자연어로 원하는 조건을 입력해 관련 공고를 찾는 흐름을 목표로 합니다.

- **체크형 상세 조건**  
  지역 · 직무 · 학력 · 경력 · 고용형태 · 급여 · 근무조건 · 기업형태 · 복리후생 등을 한눈에 보고 바로 고릅니다.

- **지역별 채용 밀도 지도**  
  숫자를 하나씩 읽기 전에 어디에 채용기회가 몰려 있는지 먼저 느낄 수 있는 지도를 지향합니다.

- **공고 탐색**  
  조건을 바꾸고, 결과를 비교하고, 관심 있는 공고를 빠르게 확인하는 흐름을 우선합니다.

## 현재 단계

`아이디어 → HOME 1차 초안 → PC 디자인 정리 → HTML/CSS/JS 구현 → 브라우저 미세조정 → 현재 메인 프로토타입`

현재 화면은 **1920×1080 PC 환경**을 기준으로 만들고 있습니다. 공고·기업·연봉·공고 수 등은 UI 구현을 위한 예시 데이터이며, 실제 데이터 연결과 기능 확장은 이후 개발 단계에서 이어갑니다.

다음 단계에서는 현재 화면을 기준으로 React 컴포넌트와 상태·이벤트 구조를 연결합니다.

## 실행

별도 설치 없이 저장소의 `index.html`을 브라우저에서 열면 현재 프로토타입을 확인할 수 있습니다.

`index.template.html`과 `jobs-panel.html`을 수정한 뒤 메인 HTML을 다시 만들 때는:

```bash
python build.py
```
