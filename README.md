# start_in

> **빠르게 찾고, 가볍게 보고, 바로 나갈 수 있는 AI 구직 탐색 프로젝트.**

`start_in`은 React · FastAPI · PostgreSQL 등 지금까지 배운 기술을 하나의 서비스 흐름으로 연결해보기 위한 학습·포트폴리오 프로젝트입니다.

대형 구직사이트처럼 정보를 많이 쌓는 것보다, **내 조건에서 지금 볼 만한 공고가 얼마나 있는지 빠르게 확인하는 경험**을 먼저 만듭니다.

## HOME · 1차 초안

![start_in home draft](assets/images/home-draft-20260919.png)

현재 홈 화면은 **1차 방향 확정본**입니다. 전체 구조는 유지하고 로고와 일부 버튼 디자인은 이후 다듬을 예정입니다.

## 핵심 경험

- **AI 채용 검색**  
  사이트 안의 채용공고 · 기업정보 · 현직자 인사이트를 바탕으로 자연어 질문에 답하고 관련 결과를 찾습니다.
- **체크형 상세 조건**  
  지역 · 직무 · 기술스택 · 경력 · 연봉 · 고용형태 · 근무형태 · 기업규모 · 학력 · 복지 · 산업군 등을 바로 선택합니다.
- **조건을 바꾸면 즉시 갱신**  
  선택할수록 공고 수와 지역별 채용 밀도가 함께 달라집니다.
- **지역별 채용 밀도 지도**  
  공고가 몰린 지역을 색과 높이 차이로 빠르게 파악하는 2.5D 지도를 지향합니다.
- **공고 정렬**  
  최신순 · 마감임박순 · 연봉 높은순 · 조회순 · 지원 많은순 · 관심 많은순 · 기업규모순 · AI 매칭순 등 실제 탐색에 필요한 기준을 우선 배치합니다.

## 상단 주요 메뉴

- **채용공고** — 실제 공고 탐색
- **기업정보** — 회사 기본정보와 채용 관련 정보
- **현직자 인사이트** — 전·현직자의 후기, 팀 분위기, 실무 경험처럼 공고만으로 알기 어려운 정보
- **합격 후기** — 지원·면접·합격 과정의 경험 공유
- **채용 Q&A** — 구직 과정에서 생기는 구체적인 질문과 답변

## 현재 상태

`제품 방향 확정 → HOME 1차 초안 확정 → 다음 단계: 공고 상세 / 기업정보 / 현직자 인사이트 화면 설계`

현재 HOME에서 아직 확정하지 않은 부분:

- 로고 심볼 최종 형태
- 일부 버튼의 최종 스타일
- 실제 데이터/API 연결
- AI 검색의 검색·추천 로직 구현
